# Icon

`icon.png` is the original generated PNG used by both plugin manifests and the
repository README. It is covered by the repository's MIT license.

Created with the built-in image generation tool using this prompt:

> Use case: logo-brand. Create a finished square 1024x1024 PNG plugin icon for Herdr skills by pcodez, an independent developer tool for coordinating a team of coding agents in visible terminal tabs. Bold minimal geometric emblem: three upright rounded terminal panels arranged as a compact H, joined by a small central connector, suggesting one coordinator and two collaborators. Warm ivory panels and a single vivid orange accent on a solid very dark charcoal square background. Flat vector-like finish, crisp edges, ample padding, instantly legible at 32px. No text, no letters as typography, no gradients, no shadows, no mockup, no watermark, no existing corporate logos. The entire image is the icon. Opaque background.

The returned image is 1254 × 1254 pixels; both directories accept this size.
