# Herdr Team wiki

Herdr Team is a Claude Code plugin that runs a task as a visible team of agents in
Herdr desktop: a master plans, reviews and gates, implementers work in their own tabs.
Its `herdr-plans` engine keeps one plan database per repository and enforces the rules
agents could forget. This wiki is the source of truth for how the plugin works.
